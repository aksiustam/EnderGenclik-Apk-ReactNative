# Mobile Application for EnderGençlik

## Features:
- A **React Native** application that works on both **Android and iOS**, managed via a website.
- **EPUB book upload** via the website, allowing users to read books within the app.
- **Push notification system** to send alerts to users.
- **TikTok-style video watching** feature.
- Built using **Expo** for mobile.
- The website is developed with **Next.js 14** and **custom CSS**.
